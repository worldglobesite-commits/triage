## Запуск
node server.mjs      # http://127.0.0.1:3000 (Node 20+, порт через PORT)
node --test          # тесты в server.test.mjs

## Где проверяется результат AI
На сервере, в `server.mjs`, функция `parseModelOutput`. Ответ модели считается
недоверенным: это должен быть валидный JSON, `topic` один из {delivery, pricing, other},
`draft` — непустая строка. Клиенту отдаются только поля `topic` и `draft`.
Ожидание модели ограничено 300 мс (`callModel`).

## Что происходит при сбое
Таймаут, ошибка модели, битый JSON, неизвестная тема или пустой черновик →
HTTP 200 `{"status":"manual_review","topic":null,"draft":null}`. Страница
показывает менеджеру сообщение "обработайте вручную" и очищает прошлый черновик.
Невалидный ввод (пустой/не строка/битый JSON/тело > 1 МБ) → HTTP 400
`{"status":"invalid_input"}`.

## Какой AI использовал
GitHub Copilot — помог с реализацией и тестами.

## Что проверил сам
В целом, всё. Проверял тесты, в том числе имитировал их падение. Проверил в браузере каждую метку (`[timeout]`, `[error]`, `[bad-json]`, `[bad-topic]`, `[empty-draft]`) и запрос, содержащий ключевики для `delivery` и `pricing`.

## Польза для менеджера
Менеджер за секунды получает готовое название темы и черновика ответа, и не придется писать их с нуля. Измерить можно, посчитав среднее время до ответа, и посчитав количество черновиков, отправленных сразу без редактирования. Также можно посчитать процент качественных готовых текстов черновиков, вычтя кейсы с manual_review из общего числа кейсов.
